# 📊 Sales Performance Analysis

## Project Overview

This project focuses on analyzing sales data using Python, SQL, Machine Learning, and Power BI. The objective is to perform Exploratory Data Analysis (EDA), build a sales prediction model, and create an interactive dashboard to generate meaningful business insights.

## Project Objectives

* Perform Exploratory Data Analysis (EDA)
* Clean and preprocess sales data
* Analyze revenue and profit trends
* Build a regression model for sales prediction
* Create an interactive Power BI dashboard
* Generate business insights and recommendations

## Dataset Information

The dataset contains sales transaction records including:

* Order ID
* Customer Name
* Order Date
* Category
* Sub Category
* Product Name
* Quantity
* Unit Price
* Total Price
* Region

## Project Workflow

### 1. Data Loading and Exploration

### 3. Exploratory Data Analysis

* Category-wise revenue analysis
* Product performance analysis

### 5. Power BI Dashboard

* Total Sales Analysis

* Discount Band Analysis

## Key Findings

* Total Sales reached 13.09M.
* Total Profit generated was 2.89M.
* Government segment contributed significantly to revenue.
* Germany showed strong sales performance.
* Product demand and pricing positively influenced total revenue.

## Recommendations

* Focus on top-performing products.
* Optimize discount strategies to improve profit margins.
* Expand sales efforts in high-performing regions.
* Use predictive analytics for future sales planning.
